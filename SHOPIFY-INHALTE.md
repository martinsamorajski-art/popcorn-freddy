# Zum Kopieren — alle Feldwerte für Kapitel 1 und 2

**Wichtig zur Übersetzung:** Shopify übersetzt Metafelder nur, wenn sie
**Textfelder** sind — JSON kann Translate & Adapt nicht übersetzen. Deshalb sind
unten alle Listen als **Textlisten** angelegt. Damit gilt für alles auf dieser
Seite: einmal auf Deutsch eintragen, dann in **Translate & Adapt** ins Englische
übersetzen — die /us-Seite zieht es automatisch. Kein zweites Feld, keine
Doppelpflege.

Feld leer lassen = der Abschnitt verschwindet.

---

## Die Definitionen (einmalig)

Settings → Custom data → Products → **Add definition**.
Bei allen: **Storefront API access = ON**.

| Name | Typ | linkes Dropdown |
|---|---|---|
| Inside list | Single line text | **List of values** |
| Page previews | File | **List of values** |
| Story title | Single line text | One |
| Story body | Multi-line text | One |
| Story hand | Single line text | One |
| Details list | Single line text | **List of values** |
| Caps | Single line text | One |
| Emotion | Single line text | One |
| Scarcity | Single line text | One |
| Guarantee | Single line text | One |
| Gift note | Single line text | One |
| Personalization label | Single line text | One |
| Chapter no | Integer | One |

Die ersten fünf reichen für die Abschnitte, um die es dir ging. Der Rest sind
Kleinteile rund um den Kaufbereich.

**Schreibweise der Listen:**

- *Inside list* — eine Zeile pro Karte: `Titel — Beschreibung` (Gedankenstrich)
- *Details list* — eine Zeile pro Tabellenzeile: `Bezeichnung: Wert` (Doppelpunkt)

Icons und Nummern setzt die Seite automatisch, in der Reihenfolge deiner Zeilen.

## Danach: Englisch für /us

1. App **Translate & Adapt** installieren (kostenlos, von Shopify)
2. Sprache **Englisch** hinzufügen und veröffentlichen (Settings → Languages)
3. In Translate & Adapt das Produkt öffnen → übersetzen lassen und nachschärfen:
   Titel, Beschreibung, SEO, und weiter unten die Metafelder (Inside list,
   Story title/body/hand, Details list …)
4. `popcornfreddy.com/us/` öffnen — dieselbe Seite, englischer Inhalt

Erscheint ein Metafeld dort nicht zum Übersetzen, dann steht seine Definition auf
JSON statt Textliste — Typ ändern und den Wert neu eintragen.

## Nach dem Ausfüllen prüfen

1. Speichern
2. `popcornfreddy.com/at/produkt/kapitel-1-fluesterwald` öffnen
3. Da sein müssen: In der Box → Blick ins Buch → Worum es geht → Auf einen Blick
4. Fehlt ein Abschnitt: Feld leer, oder bei der Definition stand
   „Storefront API access" auf OFF
