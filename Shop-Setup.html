Dein Shop-Fahrplan

Von der schönen Seite zum echten Shop.

Dein Design bleibt zu 100 % erhalten. Snipcart, Stripe, sevDesk und Brevo docken nur an — jeder Baustein macht einen Job. Diese Seite ist deine Reihenfolge zum Abhaken.

✓ Schon erledigt (von mir)

  • Kaufbutton ist ein Snipcart-Button — inkl. Pflichtfeld „Name des Kindes" (Kapitel 1 & 2)
  • Preise, Artikelnummern, GPSR-Pflichtangaben auf den Produktseiten
  • Snipcart-Loader eingebaut — eine Datei, ein Key
  • Umschalter: bis dein Key drin ist, läuft der bisherige Warenkorb weiter — kein Doppelsystem
  • Alle Rechtsseiten als Platzhalter-Gerüst, lokale Schriften (DSGVO)

→ Das machst du

  • Snipcart-Konto + Public API Key eintragen
  • GitHub + Netlify verbinden (Auto-Deploy)
  • Stripe verbinden (kann zuletzt)
  • sevDesk für Rechnungen anbinden
  • Brevo für den Newsletter
  • Rechtstexte final vom Anwalt einsetzen

1 Snipcart-Konto & Key

Das ist der einzige Schritt, der den Shop „anschaltet".

  1. Auf snipcart.com registrieren (kostenlos; 2 % fallen erst im Live-Betrieb an).
  2. Dashboard → Account → API Keys.
  3. Den PUBLIC API KEY kopieren. Niemals den geheimen Secret Key in die Website!
  4. Datei snipcart-loader.js öffnen und den Key hier einsetzen:
window.SNIPCART_API_KEY = "DEIN_PUBLIC_API_KEY";

Sobald ein echter Key drinsteht, übernimmt Snipcart automatisch Warenkorb + Kasse. ✎

Vor dem echten Livegang

In snipcart-loader.js steht die Test-/Live-Logik über deinen Key. Snipcart läuft zunächst im Test-Modus (Test-Kreditkarten, kein echtes Geld), bis Stripe verbunden und der Live-Key hinterlegt ist.

2 GitHub + Netlify

Das löst dein „drei Versionen"-Problem dauerhaft — und macht Änderungen automatisch live.

Warum GitHub?

  • Versionsverlauf — jede Änderung gespeichert, nichts geht mehr verloren (wie damals die Gutschein-Funktionen).
  • Eine Quelle der Wahrheit — nie wieder „welcher Ordner ist aktuell".
  • Auto-Deploy — GitHub an Netlify koppeln: Änderung gespeichert → Seite baut sich selbst neu. Kein manuelles Hochladen.
  1. Kostenloses Konto auf github.com.
  2. Ein Repository anlegen, den Projektinhalt hochladen (kann ich für den Export vorbereiten).
  3. In Netlify → Add new site → Import from Git → dein Repo wählen. Publish-Verzeichnis: .
  4. Fertig: ab jetzt genügt „speichern in GitHub", und Netlify stellt es live.

3 Stripe — Zahlung später möglich

Apple Pay & Google Pay sind automatisch dabei.

  1. Konto auf stripe.com, Firmendaten + Bankverbindung hinterlegen.
  2. Snipcart-Dashboard → Payment Gateway → Stripe verbinden (ein Klick, kein Code).
  3. Apple/Google Pay aktivieren sich damit von selbst.

Sicherheit

Kartendaten laufen nie über deine Seite — direkt zu Stripe (PCI-DSS Level 1). Du haftest nicht für Kartendaten.

4 sevDesk — Rechnungen

Rechtssichere österreichische Rechnung, automatisch aus jeder Bestellung.

  1. sevDesk-Konto (Tarif „Rechnung"), UID + Firmendaten eintragen; Rechnungsnummernkreis + Steuersätze (20 % / 10 %) einmalig einstellen.
  2. Brücke Snipcart → sevDesk über Make.com (oder Zapier):
    • Auslöser: Snipcart „Order completed" (Webhook)
    • Aktion: sevDesk „Rechnung erstellen" mit Positionen + Kundendaten
  3. Eine Testrechnung prüfen.

Wichtig

Snipcarts eigener „Receipt" ist ein Kaufbeleg, keine finanzamtstaugliche Rechnung. Für Österreich braucht es die echte sevDesk-Rechnung (fortlaufende Nr., UID, MwSt.).

5 Brevo — Newsletter

Double-Opt-In, Bestätigungsmail, Abmeldelink — macht Brevo komplett selbst.

  1. Konto auf brevo.com (gratis bis 300 Mails/Tag).
  2. Double-Opt-In aktivieren, Bestätigungs- & Abmeldeseite hinterlegen.
  3. Das Newsletter-Formular der Seite auf Brevo zeigen lassen (sag Bescheid, ich verdrahte es).

6 Bestellungen & Kindername sehen

Snipcart-Dashboard → Orders → Bestellung öffnen.

Dort stehen Adresse, Kapitel, Betrag und „Name des Kindes: …" — das ist deine Druck- und Versandliste. Der Name reist automatisch mit und landet auch auf der sevDesk-Rechnung.

7 Vor dem Livegang

  • Public API Key in snipcart-loader.js eingetragen
  • Preise geprüft (39.90 mit Punkt) auf allen Produktseiten
  • data-item-url = volle Live-URL der jeweiligen Produktseite (sobald Domain steht)
  • Stripe verbunden, Test-Bestellung erfolgreich
  • sevDesk-Automatik getestet (eine Testrechnung geprüft)
  • Datenschutzerklärung final (Snipcart, Stripe, sevDesk, Brevo + AVV-Verträge; Kindername als Verarbeitungszweck) — vom Anwalt / abmahnsicheren Anbieter
  • 2-Faktor-Login bei Snipcart, Stripe, sevDesk, GitHub, Netlify aktiviert

Kosten grob

~20–30 €/Monat planbar (v. a. sevDesk) + ~3,5 % pro Bestellung (Snipcart 2 % + Stripe 1,5 %). Netlify & Brevo starten gratis.
